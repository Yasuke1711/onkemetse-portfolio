# The Grand House

A multi-page boutique hotel website concept set in Gardens, Cape Town.

## Pages
- Home and stay search
- Rooms and suites
- Dining
- Cape Town neighbourhood guide
- Availability and rate comparison
- Reservation review and enquiry summary

## Run locally
This is a static HTML, CSS and JavaScript website. Open `index.html` in a browser or serve this folder with any static file server.

## Deploy on Vercel
Import the repository or deploy this folder as a static site. No build command is required. Set the output directory to this folder if deploying from a monorepo.

## Demo behaviour
The date search, room comparison, sample rate calculations, optional extras and enquiry summary work in the browser. Prices and availability are illustrative. The site does not connect to a property management system, accept payments, send guest details or place real reservations.

## Package positioning
This concept represents the P6,000 Enhanced hospitality website tier: a multi-page property presentation, richer room and dining content, and a guided booking-enquiry journey.

The Grand House, property details, room descriptions, menu, prices and policies are fictional concept content.
