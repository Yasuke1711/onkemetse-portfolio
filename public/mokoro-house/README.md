# Mokoro House

A responsive, one-page hospitality website concept for an imagined safari retreat in Botswana's Okavango Delta.

## Preview
When deployed from the portfolio's public directory, the site is available at /mokoro-house/.

## Features
- Responsive navigation and editorial landing page
- Delta landscape storytelling with UNESCO reference
- Interactive seasonal guide with careful notes on annual variation
- Three illustrative accommodation directions
- Safari experience overview
- Client-side stay brief builder with copy interaction
- Accessible labels, keyboard focus states and reduced-motion support

## Important concept note
Mokoro House is fictional. It is not an operating lodge, does not accept bookings, and makes no claims of existing rooms, prices, staff, awards, conservation outcomes or community partnerships. The enquiry tool only creates a local text brief in the browser; it does not transmit or store information.
